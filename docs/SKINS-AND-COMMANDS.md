# Skins and commands

Spoilers: this page says where every hidden skin is. Skins belong to the save file. Pick one in Settings > Skin.

## Every skin

| Skin | How to get it | What it is |
| --- | --- | --- |
| Midnight | Free | The default: charcoal and brass. |
| Felt | Free | Card-table green. |
| Daylight | Free | Light, for bright rooms. |
| Neon | Press the **10** in the logo ten times in a row | Electric cyan and pink. |
| LCD | Press the version number in the footer seven times | Green segment-display glow. |
| Blueprint | Search the Collection for **blueprint** | White lines on a blueprint grid. |

| Console | Unlocked with Terminal | The whole game as a command line. |
| Chat | Type **hello** into any command line | The whole game as a chat with Tenny, a bot. |

| Calculator | Look up **07734** in the Collection's number lookup (it says hELLO upside down) | The whole game on a calculator. |
| Gold, Ruby, Aurora | Buy the bundle for 500 coins in Settings | Three rich palettes. |

| Vaporwave | Complete the Memes page | Pink and purple. |
| Spectrum | Complete the Combos page | Clean and bright. |

To leave a full-screen skin, use its Leave chat, Power off or OFF button, or type GUI in Console. You go back to the skin you wore before.

## Console and the Settings command line

Both understand the same commands. Upper or lower case both work; the up and down arrows bring back earlier commands.

| Command | What it does |
| --- | --- |
| `ROLL [n]` | Roll once, or n times (up to 10,000) and show the best |
| `AUTO [tier]` | Roll until a tier or better, e.g. `AUTO mythic` |
| `ENDLESS` / `STOP` | Roll until you type STOP |
| `SPEED 1`, `SPEED 2`, `SPEED TURBO` | Auto and Endless speed |
| `RATE 90`, `250`, `500` or `1000` | Turbo rolls per second |
| `MODE [name]` | Show or change the mode |
| `STATS` | Totals, best roll, collection, coins, prestige |
| `LUCK [mode]` | Your tiers against the expected shares |
| `LOG [n]`, `BEST [mode]` | Recent rolls, hall of fame |
| `INV` | Inventory and active effects |
| `USE item` | Use an item, e.g. `USE luck100` or `USE goose` |
| `FUSE item`, `FUSE item ALL`, `FUSE ALL` | Fuse once, as often as you can, or everything |
| `SPIN [n or ALL]`, `ODDS` | Spin the coin slot, see its prize table |
| `QUESTS`, `QUESTS CLAIM n` | Daily quests |
| `BOOK`, `BOOK CLAIM page` | Badge book |
| `BADGES [word]` | Badges by category, or every badge matching a word |
| `ACH` | Achievements |
| `PRESTIGE`, `PRESTIGE YES` | Progress, or prestige |
| `SKINS`, `SKIN id`, `BUY BUNDLE` | Your skins, wear one, buy the bundle |
| `SOUND ON` / `OFF` | Sound |
| `VER`, `CLS`, `GUI`, `HELP` | Version, clear, leave Console, list commands |

## Chat

Talk to Tenny in plain words, or tap the buttons above the message box. Tenny understands every Console command ("roll 100", "use goose", "fuse all", "stats") plus a bit of small talk, and reacts to your rolls. During Auto and Endless, Tenny tells you about every Legendary or rarer roll. Say "bye" to leave.

## Handheld

| Button | Keyboard | What it does |
| --- | --- | --- |
| D-pad | Arrow keys | Move through the menu |
| A | Z or Enter | Choose: roll, auto, endless, items, slot, stats, quests, mode |
| B | X, Backspace or Escape | Back |
| ▶ on an item | Right arrow | Fuse all of that item |
| START | Space | Run or stop Endless |
| SELECT | Shift | Next mode |

The screen shows your last roll, its tier and 1/N, then the menu, then your mode and coins.

## Calculator

The display holds ten digits, exactly one roll.

| Key | Keyboard | What it does |
| --- | --- | --- |
| 0 to 9 | 0 to 9 | Type how many rolls you want |
| = | Enter or = | Roll that many (1 if you typed nothing) and show the best |
| + | + | Run or stop Endless |
| − | - | Stop |
| × | * or x | Use your strongest luck charm |
| ÷ | / | Fuse everything |
| MR | | Show your best roll ever |
| M+ | | Star the last roll |
| MODE | m | Next mode |
| SPIN | s | Spin the slot (type a number first to spin that many) |
| C | Escape or c | Clear, and stop rolling |
| OFF | | Leave the calculator |
